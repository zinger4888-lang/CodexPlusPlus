QuotaBar — остаток квот Codex в меню-баре macOS.

Обновление: при запуске, каждую минуту, после пробуждения Mac.
Данные запрашиваются через локальный Management API EasyCLIProxyAPI.
Авторизация повторно не нужна. Ключ управления читается из конфигурации роутера и не копируется в приложение.

5h и Weekly показывают сумму остатков включённых аккаунтов, отдельно для каждого окна.
100% — полная относительная квота одного аккаунта. Разные тарифы могут иметь разную абсолютную ёмкость.
Исчерпанный лимит одного окна не обнуляет остаток другого. Число доступных для запросов аккаунтов показано отдельно в меню.
Выключенные аккаунты исключаются из суммы и её максимума.
Знак ? — часть квот неизвестна. Знак ~ — данные устарели или роутер недоступен.
По клику: аккаунты, время сброса лимитов, время обновления, ручное обновление и выход.

Сборка: ./build.sh (нужны Xcode Command Line Tools).
Установлено: /Applications/QuotaBar.app.
Автозапуск: ~/Library/LaunchAgents/local.zinger.quotabar.plist.
Обновление внутри окна EasyCLIProxyAPI не изменяется: у виджета собственный таймер.
